# iSports API

Live sports data provider offering key-authenticated REST/HTTP feeds for football and basketball, including livescores, schedules, results, events, stats, standings, odds, and embeddable widgets. Covers 2000+ football leagues/cups and 800+ basketball leagues/cups.

- **Provider:** https://www.isportsapi.com/en/

- **Base URL:** http://api.isportsapi.com/

- **iSports REST API** — Query-param key-authenticated REST/HTTP API for live sports data (football and basketball): livescores, schedules, results, events, stats, lineups, standings, player stats, and odds. GET-only with per-endpoint rate limits. (`http://api.isportsapi.com/`)
