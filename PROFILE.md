# iSports API

Sports-data provider delivering real-time live scores, comprehensive match data, betting odds, and 20 years of historical datasets for football (soccer) and basketball, covering 2,000+ football leagues and 800+ basketball leagues via key-authenticated RESTful JSON endpoints.

- **Provider:** https://www.isportsapi.com/en/
- **Documentation:** https://www.isportsapi.com/en/docs.html
- **Base URL:** http://api.isportsapi.com/sport/

## APIs

- **iSports Sport Data API** — REST over HTTP returning JSON for football and basketball live scores, match stats, standings, player/team data, historical datasets, and betting odds. Authenticated via a static api_key query parameter. Consistent JSON envelope where code 0 indicates success. (`http://api.isportsapi.com/sport/`)

> REST/JSON API is publicly reachable at http://api.isportsapi.com/sport/ (mirror http://api2.isportsapi.com) with example form GET http://api.isportsapi.com/sport/football/livescores?api_key=YOUR_API_KEY, but a trial/subscription key is required and full docs are gated behind login.
