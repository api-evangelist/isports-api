# iSports API (isports-api)

iSports API is a sports-data provider selling key-authenticated REST/HTTP feeds for football (soccer) and basketball to sportsbooks, media sites and app developers. The catalogue covers 2,000+ football leagues and cups and 800+ basketball leagues and cups across 113 documented GET endpoints: livescores and delta feeds, schedules and results, match events and shooting data, lineups, live text commentary, team, player and referee profiles, transfers, league and cup standings, player and match statistics, FIFA rankings, multi-language name packs, and pre-match, in-play, future and historical odds from 200+ bookmakers. It also ships iframe-embeddable live-animation and livescore widgets. Every response uses the same {code, message, data} envelope returned over HTTP 200, authenticated with an api_key query parameter, and is sold as per-product monthly, quarterly or yearly subscriptions with a 15-day free trial.
