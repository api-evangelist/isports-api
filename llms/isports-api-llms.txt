# iSports API

> Key-authenticated REST/HTTP sports data feeds for football (soccer) and basketball: livescores, schedules and results, match events, lineups, live text, statistics, standings, team/player/referee profiles, transfers, multi-language name packs, live-animation embeds, and pre-match, in-play and historical odds across 200+ bookmakers. Coverage is 2,000+ football leagues and cups and 800+ basketball leagues and cups.

All 113 documented operations are GET, authenticated with an `api_key` query parameter, and return the same `{code, message, data}` JSON envelope over HTTP 200 — including on failure, where `code` is non-zero (`2` = invalid api_key). There is no OpenAPI definition, no webhook or streaming surface, and no `/.well-known/` discovery; change detection is poll-based through paired `/changes` and `/modify` endpoints. Access is by paid subscription per product, with a 15-day free trial (200 calls/day per sport, ~2 minute live-data delay).
